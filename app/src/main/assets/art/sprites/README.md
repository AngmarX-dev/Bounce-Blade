# Sprite assets

Add transparent PNG or WebP sprites here. Recommended names:

- `blade.png` — player blade.
- `enemy_basic.png` — basic enemy.
- `crate.png` — destructible crate.
- `switch.png` and `exit.png` — level objects.
- `effects/` — sparks, trails and impact effects.

Keep original editable files (such as layered PSDs) in a separate source-assets folder or repository if they are large.
