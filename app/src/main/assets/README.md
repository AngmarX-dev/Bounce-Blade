# Game assets

Put runtime-loaded content here. Files in `assets/` are not compiled as Android resources; use `assets.open("relative/path")` to read them.

- `levels/`: level JSON definitions.
- `art/sprites/`: blade, enemies, crates, switches and effects.
- `art/backgrounds/`: arena backgrounds and parallax layers.
- `audio/music/`: background music.
- `audio/sfx/`: short sound effects.
- `fonts/`: licensed font files.

Replace the README files in these folders with your actual assets when ready.
